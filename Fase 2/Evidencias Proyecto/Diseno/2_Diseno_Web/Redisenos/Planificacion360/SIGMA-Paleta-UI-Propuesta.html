Paleta de marca aplicada a la interfaz

Una guía para alternar morado, azul y turquesa en botones, cards y estados sin convertir cada pantalla en un arcoíris.

01 · Fundación

Colores extraídos del logo

El morado identifica la acción principal; el turquesa distingue la acción complementaria; el azul conecta navegación e información.

Acción principal
Violeta SIGMACTA, pestaña activa, foco de marca.
Navegación

Acento claro
Turquesa SIGMAFondos suaves, gráficos y foco.
Acción secundaria
Turquesa oscuroBotones secundarios con texto blanco.
02 · Acciones

Jerarquía de botones

La alternancia ocurre por función, no por decoración. Una acción conserva el mismo color en todo SIGMA.

Acciones operativas

Usar morado para confirmar y turquesa oscuro para una acción paralela.

Ejemplo: Generar OT = morado · Reprogramar = turquesa · Abrir plan = contorno azul.

Estados del botón

El color de marca no reemplaza los estados semánticos.

Regla: rojo queda reservado para acciones destructivas; nunca se usa solo para “variar”.

05 · Navegación y formularios

Pestañas, filtros y foco

El morado marca ubicación; el turquesa marca foco. Así cada color cumple una tarea distinta.

07 · Criterio

Qué hacer y qué evitar

Aplicación recomendada

Una acción morada y una secundaria turquesa por grupo. Cards neutras, chips suaves y cabeceras con degradado de marca.

Evitar

Texto blanco sobre el turquesa claro, alternar colores sin significado o usar morado para alertas críticas y errores.
